# Моя колекція · v0.1.0

Незалежний персональний PWA для колекціонерів. **«Мій графік» не змінено.**

Функції: вкладені папки; картки фігурок з фото, номерами, виробником, станом, кількістю, роком і двома цінами; позначення наявності; бажанки; прогрес серій; ручні записи історії ринкових цін; шість тем; чекліст; статистика; BarcodeDetector за підтримки браузера; локальна IndexedDB; резервні JSON-копії із фото; поширення URL; PWA офлайн.

**Обмеження:** автоматичне наповнення каталогів і автоматичні ринкові ціни ще не підключено. Для цього потрібні перевірені дозволені API. Резервні копії у поточній версії — JSON, не ZIP. Збереження локальне, без синхронізації.
